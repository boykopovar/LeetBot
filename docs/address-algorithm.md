# Алгоритм выдачи адресов

Каждый пользователь получает **2 097 152 непересекающихся адреса**, детерминированно вычисляемых из `user_id` без базы данных.

```
inp = user_id * 2097152 + nonce   (nonce — случайное 21-битное число)
```

`inp` шифруется 8-раундовой Feistel-сетью с ключом `ENCRYPT_KEY` и кодируется в 8 слогов из алфавита 150 слогов (строка 16–24 символов).

Верификация адреса — расшифровка и проверка `decrypted // 2097152 == user_id`.

Общее пространство: `150^8 ≈ 2.56 × 10^17` адресов, максимум ~122 млрд пользователей без коллизий.

Если `user_id` выходит за пределы допустимого диапазона, генерация адреса невозможна — бот сообщит об этом в чат.
