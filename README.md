# LeetBot

Временный почтовый ящик в Telegram. Бот принимает входящие письма на одноразовый адрес и пересылает их вам как документ.

## Быстрый старт

```bash
pip install -r requirements.txt
python main.py
```

При первом запуске создаётся `.env` с дефолтными значениями. Обязательные переменные — `BOT_TOKEN`, `ENABLED_IDS`, `DOMAIN`.

## Команды Telegram

| Команда | Действие |
|---|---|
| `/random` | Сгенерировать случайный одноразовый адрес |
| `/stop` | Остановить активную сессию |
| `/apikey` | Получить JWT-токен для REST API |
| любой текст | Зарегистрировать конкретный адрес вашего домена |

Доступ ограничен белым списком `ENABLED_IDS`. Администраторы из `ADMIN_IDS` могут регистрировать любой адрес домена.

## Как работает

1. Отправьте `/random` или введите адрес вручную — бот создаёт сессию на `SESSION_MINUTES` минут.
2. Используйте этот адрес для регистраций, подтверждений и прочего.
3. Когда придёт письмо, бот пришлёт его HTML-версию как документ.
4. Сессия истекает автоматически или по команде `/stop`.

Управление сессиями доступно через HTTP — удобно для автоматизации. Подробнее: [docs/api/overview.md](docs/api/overview.md).
